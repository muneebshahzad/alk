DigiDokaan Sandbox API

Verified endpoint structure from DigiDokaan's testing environment and Android client.

This is a verified integration worksheet, not an official DigiDokaan Swagger page. DigiDokaan does not expose public OpenAPI documentation at its common documentation URLs.

Authentication example

POST https://dev.digidokaan.pk/api/auth/login
Accept: application/json
Content-Type: application/json

{
  "phone": "YOUR_PHONE",
  "password": "YOUR_PASSWORD"
}

Observed sandbox limitations

The test account has no approved pickup/courier connection.

get_courier_shipper returned: “Kindly contact your sales person to approve this pickup first.”

Production tracking numbers returned 404 - No Order Found in sandbox. Sandbox and live records are isolated.

Fields present in the Android client

The client includes tracking fields named courier_tracking_status, courier_status, courier_status_date, courier_status_reason, trackingNo, and courier_weight. Exact production response bodies still need validation with an approved live account.
